## はじめに
macOS標準コマンドでファイルサイズを取得する方法まとめ

```:test.txt (対象テキストファイル)
hello
world
```

## 動作環境
* macOS Tahoe 26.3

:::message
本記事ではmacOS標準のBSD系コマンドで検証しています
:::

---

## `stat`
```bash
➜ stat -f %z test.txt
12
```
論理サイズ(ファイルの中に格納されているデータ量) 

## `ls -la`
```bash
➜ ls -lh test.txt
Permissions Size User Date Modified Name
.rw-r--r--@   12 test 20 Oct  2025  test.txt
```
`stat`の結果を人間が読みやすい形式にして表示
基本こっち使っておけばいい

## `du -h`
```bash
➜ du -h test.txt
4.0K    test.txt
```
ディスク上で確保されている容量

macOS/APFSでは4096byte単位で割り当てられるため、本来のデータ量は`12byte`であっても、`4096byte`が確保される

macOS標準コマンドの場合、`KiB`(K=1024byteとして扱う)を使う

## 結論
`ls -la`を使ってパット見でわかりやすい表示にするのが無難
